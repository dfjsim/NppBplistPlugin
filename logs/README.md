# NppBplistPlugin Logs Directory

This directory contains debug logs generated by the NppBplistPlugin for Notepad++.

## Log Files

Log files are automatically created with timestamps in their filenames:
- Format: `NppBplistPlugin_YYYYMMDD_HHMMSS.log`
- Example: `NppBplistPlugin_20250929_143052.log`

## Log Levels

The plugin logs at different levels:
- **DEBUG**: Detailed diagnostic information for troubleshooting
- **INFO**: General informational messages about plugin operation
- **WARN**: Warning messages for potential issues
- **ERROR**: Error messages for failures and exceptions

## When Logs Are Useful

Logs are particularly helpful when:
1. Certain bplist files crash Notepad++
2. Conversion between bplist and XML fails
3. Investigating unexpected behavior
4. Debugging timestamp conversion issues

## Log Contents

The logs capture:
- Plugin initialization and shutdown
- File open/save/close events
- Buffer activation events
- Conversion operations (bplist ↔ XML)
- Date/timestamp conversions
- All errors and exceptions with stack context
- libplist API calls and their results

## Cleanup

Log files can be safely deleted at any time. They are not required for plugin operation.
